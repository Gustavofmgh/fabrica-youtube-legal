Privacy Policy

Last updated: October 14, 2026.

Fabrica YouTube is a personal publishing tool operated by the owner of the YouTube channel The Why Behind It. Only the channel owner signs in to it.

Data accessed

With the owner's consent, the tool uses the YouTube Data API to confirm the identity of the owner's channel and to upload, schedule and set thumbnails for the owner's own videos. It does not read, collect or process data about viewers or any other YouTube user.

Storage

OAuth tokens are stored only on the owner's computer, with access restricted to the owner's user account. No data is sent to any server other than Google's APIs.

Sharing

No data is sold, shared, transferred or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
